¿Cómo funciona "Para ti"?

La app lee directamente el archivo jobs.json alojado en tu repositorio GitHub.

Un script de GitHub Actions (gratis) lo actualiza automáticamente cada día a las 6am Chile, scrapeando CompuTrabajo y Trabajando.com.

Sin servidor · Sin API key · Sin costo — exactamente igual que la app de Entel.
